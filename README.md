YakLudka — Provably Fair
Скрипт для независимой проверки честности раундов Crash, PvP, Arena и Gravity в YakLudka (Telegram Mini App).

Как это работает
Сервер заранее фиксирует результат раунда секретом server_seed и публикует только его хеш. Угадать по хешу результат невозможно, а подменить секрет после ставок уже нельзя: другой секрет даст другой хеш. После раунда секрет раскрывается, и любой может пересчитать результат сам.

PvP / Arena / Gravity — две проверки, обе обязательны:

Секрет не подменён: sha256(f"{game}_seed:{server_seed}") == опубликованный хеш.
Билет получен из секрета: sha256(f"{game}_ticket:{round_id}:{total_tickets}:{server_seed}") % total_tickets + 1 == победный билет.
Хеш публикуется, когда в раунде набирается минимум игроков.

Crash — server_seed_hash = sha256(f"{round_id}:{crash_point:.2f}:{server_seed}"). Хеш публикуется при старте раунда, когда икс краха уже зафиксирован; после краха раскрывается server_seed.

Где взять данные
Окно «Честная игра» (кнопка-щит) в режиме → блок «Прошлые раунды» → раскройте раунд: там Server Seed, хеш, номер билета и число билетов. Приложение само пересчитывает их и ставит «✓ Проверено», а этот скрипт позволяет проверить независимо.

Использование
python verify.py crash --round-id 1234 --result 2.35 --server-seed <hex> --server-seed-hash <hex>
python verify.py pvp --round-id 1234 --total-tickets 57 --result 41 --server-seed <hex> --server-seed-hash <hex>
python verify.py arena   ... (те же параметры)
python verify.py gravity ... (те же параметры)
Скрипт выводит промежуточные вычисления и итог: ЧЕСТНО или НЕ СОВПАДАЕТ.

Нужен только Python 3.9+, без сторонних зависимостей.
